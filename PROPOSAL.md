# Daily Productivity Tracker — Proposal

## What I am building
I want to build a website that helps people track their daily habits and calculates how productive their day was.

## Who it is for
This tool is for college students like me who want to manage their time better and see how their daily habits affect their productivity.

## What it remembers
The website will remember daily study hours, sleep hours, exercise minutes, screen time, and previous productivity scores.

## Where the data lives
The data will be stored in JavaScript and saved using localStorage so it stays there when the page is refreshed.

## What each action changes
- Adding a daily entry saves the habits and calculates a productivity score.
- Selecting a previous day displays that day's score and habits.
- Deleting an entry removes it and updates the weekly average.
- Resetting the tracker clears all saved entries.

## Features
1. Enter daily habits using a form.
2. Calculate a productivity score out of 100.
3. View previous daily scores and a weekly average.
4. Display progress using a simple chart.
5. Reset or delete saved information.

## What I do not know yet
I need to learn how JavaScript stores information, calculates scores from multiple inputs, updates the webpage automatically, and uses localStorage to save data.
