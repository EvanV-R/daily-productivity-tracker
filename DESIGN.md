# Design Direction

## Overall Design

For my Daily Productivity Tracker, I chose a clean and simple student dashboard design. I wanted the website to be easy to use without making it look too complicated.

The website uses an off-white background, white cards, rounded corners, dark navy text, and indigo accents. I wanted users to be able to quickly enter their daily habits and understand their productivity scores.

## Design Options

### Option A: Clean Student Dashboard (Chosen)

This design uses a simple layout with summary cards at the top, a form for entering daily habits, and a seven-day productivity chart with a history section below.

I chose this direction because it is organized, easy to understand, and works well for students who want to track their habits quickly.

### Option B: Dark Dashboard (Alternative Considered)

Another idea was to use a dark background, a sidebar for navigation, and a larger chart as the main focus.

I decided not to use this approach because it would make the website more complicated than necessary. My main goal was to make something simple that students could use every day.

## Final Design Decision

I chose Option A because it fits the purpose of my project better. The layout keeps the most important information visible and makes it easy to add new entries, review previous days, and track productivity over time.

## Mobile Design

On smaller screens, the cards and form fields stack vertically so the website is easier to use on a phone.

## User Feedback and States

- **Empty state:** The website provides guidance when no entries have been saved.
- **Active state:** Productivity scores, the chart, and history update when users add information.
- **Error state:** Invalid inputs show an error message.
- **Reset state:** Users can clear their saved entries and return to the empty state.

## Final Goal

My goal was to create a functional productivity tracker that looks professional but is still simple enough for someone to use without instructions.
